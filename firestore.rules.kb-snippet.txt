Knowledge Base — Firestore rules
================================
The Knowledge Base tab stores data in two NEW collections. Add these inside
`match /databases/{database}/documents { ... }` (Firebase Console -> Firestore -> Rules), next to the PKT rules:

  match /trackerKb/{id}          { allow read, write: if request.auth != null; }
  match /trackerKbFeedback/{id}  { allow read, write: if request.auth != null; }

Sandbox is already covered by the sbx_ rule in firestore.rules.sandbox-snippet.txt.
As elsewhere in Align360, who may edit is enforced in the app, not by Firestore (no backend).
